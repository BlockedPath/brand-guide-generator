          How it works

          Three TinyFish APIs, one guide

          01

          Fetch core extraction

          Reads the homepage and up to 7 brand, about, product and pricing pages as clean Markdown, plus the page head's schema.org data. All messaging, tone of voice, official brand rules, the declared logo and social profiles come from that text.

          02

          Search discovery

          Turns a company name into its official site, then searches the brand's own domain for guidelines, press kits, trademark rules and values pages that homepages rarely link to.

          03

          Browser visual tokens

          Renders the homepage in a remote Chrome and measures what actually paints: computed colours, the fonts Chrome drew, button styles and the header logo. Fetch strips styling, so this is the only way to see it.

          Outputs brand.htmlbrand.jsontokens.jsontokens.csstailwind.preset.jsbrand.md

          API

          Use it from anywhere

          HTTP
          GET /api/guide?q=linear.app           # structured brand guide (JSON)
GET /api/guide/stream?q=Patagonia     # Server-Sent Events: live progress, then links
GET /api/guides                       # everything generated so far
GET /g/<domain>/tokens.json            # W3C design tokens → Figma Tokens Studio
GET /g/<domain>/tokens.css             # CSS custom properties
